# Research Team Manager 1.4.0

## Updates from GitHub releases

- WordPress now offers Research Team Manager updates from this repository's GitHub releases, in **Dashboard → Updates** and on the Plugins screen, like Zoer Connect.
- A download is accepted only when its SHA-256 matches the `update.json` published with that release. Automatic background updates stay off; an administrator starts each update.
- Sites that installed the plugin under another folder name (for example from a branch ZIP) are updated in place.
- **1.3.2 and earlier have no updater.** Install 1.4.0 once by uploading `research-team-manager-1.4.0.zip` (**Plugins → Add New → Upload Plugin → Replace current with uploaded**). Later releases arrive automatically.

## Team workspaces: a menu and permissions per PI

Multiple-teams mode, configured in **Team Settings → Team workspaces**.

- **A sidebar menu per team.** Each menu is named after the team's PI(s) or the team, and you choose which teams get one. It has Overview, Members, Add Member, Publications and Team Settings. Every link opens the normal screen filtered to that team, new members join it, and the menu stays highlighted while you work in it.
- **Two access models.**
  - **Open:** anyone who manages team members can open every team.
  - **Restricted:** administrators and editors see everything. Other users see only the teams assigned to them, through their team menus. They can't open other teams' members, team settings or publications, and their saves never remove a member from teams they don't manage.
- **New "Research Team Manager (PI)" role.** It manages members, uploads media, edits its team's settings and syncs its team's publications. It can't write posts or pages, create or delete teams, or change plugin settings.
- **Assigning teams to users.** Use *Research teams* checkboxes on **Users → Add New** and on user profiles, or *Team managers* checkboxes on each team's edit screen. The Users list shows each user's teams.
- **Blocks.** Team member Query Loops, including the Researcher Directory, get a **Teams / PIs** sidebar panel: all teams, or tick one or more. The new **Team Section** block shows one team's header, roster or publications.
- **Capabilities.** Team members now use their own capabilities (`edit_rtm_members`, …). On update, every role receives the member capabilities matching the post capabilities it already has, so existing editors, authors and contributors keep the same access.

## Researcher directory (from University Research Network 1.2.1)

The University Research Network add-on is now part of the plugin. Turn it on in **Team Settings → Researcher directory**. It switches on automatically for sites that already have data from the add-on.

- Profile taxonomies: Faculty, Department, Appointment type, Graduate supervision, Research theme, HRI membership and Institution / affiliation. Research topics are available in the block editor.
- A "Research network affiliations" meta box. Saving it fills the Institution taxonomy with normalized names.
- An "UNBC source and review notes" meta box for members imported from the university directory.
- A keyword search index covering names, positions, biographies, affiliations, imported source details and every directory taxonomy.
- Blocks: **Researcher Field** (portrait/initials, position, institution, affiliations, faculty and department, appointments, expertise, supervision, topics, themes, membership, biography, email, links, labs and source), **Researcher Filters** and **Directory Tabs**. There is also a **Researcher Directory** Query Loop variation with filters and pagination.
- Patterns: **University Researcher Directory**, plus a new **Researcher Profile** pattern for the single team member template.
- A theme multi-select filter for the labs view, and portrait fallback to initials when a source photo cannot load.
- The block names, taxonomies and meta keys are unchanged, so existing pages and imported records keep working. While the old add-on is still active, Research Team Manager leaves the directory to it and shows a notice asking you to deactivate it.
- New filters: `rtm_network_directory_url`, `rtm_network_directory_page`, `rtm_network_taxonomies` and `rtm_network_taxonomy_labels`.

## Fixes

- The Query Loop "Team Member Sorting" editor extension shipped as uncompiled JSX and failed to load in the block editor. It is now plain JavaScript and appears for Team Member Query Loops.
- The editor script is versioned with the plugin, so browsers stop serving the cached broken copy.
- Removed an editor filter registered under an invalid hook name. It never ran and only logged a console error.

## Package

The release ZIP contains only runtime files. Documentation, block sources, Node metadata and the standalone `utilities/` import scripts stay in the repository and are no longer copied to sites.
